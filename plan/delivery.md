# Delivery artefacts

Every knowledge topic must show up in the product, not only in documents.

Include at least:

- Task management: milestones; CSV of broken-down tasks importable into Jira, Asana, Trello, or similar
- API: contract; documentation (Swagger or similar)
- Backend: code documentation; modular code; single-responsibility modules; unit tests
- Frontend: code documentation
- Database: data models; queries; migration scripts if needed
- Testing and QA: test plans; UAT on Vercel; live platform on Vercel
