# GitHub Projects board and Roadmap

**Schedule of record:** GitHub Projects Roadmap (Gantt analogue).  
**Task list of record:** `plan/tasks.csv` (importable to GitHub, Jira, Asana, or Trello).

Course text in `product/constraints.md` names Asana, Instagantt, or TeamGantt. This team uses GitHub Projects because it is $0 and sits on the same repo as the code. If the mentor rejects that, import `plan/tasks.csv` into the named tool. Do not invent a second WBS.

## Fields

- Status: Backlog, Ready, In progress, Review, Done
- Milestone: M3 … M8
- Assignee: domain lead email
- Priority: Must / Should / Could / Won’t
- Start date and target date (Roadmap)

## Create the project (once the GitHub remote exists)

1. GitHub → repo → Projects → New project → Board.
2. Add a Roadmap view. Set start and target dates from the CSV.
3. Import `plan/tasks.csv` (Projects: Import items, or Issues from CSV then add to the project).
4. Invite Abhilash and Eagle as viewers if they have GitHub accounts; otherwise screenshot the Roadmap into Tuesday evidence.

Until a remote exists, the CSV **is** the board. Status in the CSV is updated in the same commit as the work.
