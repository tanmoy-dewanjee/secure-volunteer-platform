# Working agreement

**Team:** C262T-4104  
**Applies:** 9 Sep 2026 through handover (27 Nov 2026)  

This is how we work. It is not optional reading. Charter SLA still stands: 15 hours per week, 24-hour absence notice, 12-hour blocker escalate.

## How we treat each other

- Speak in stand-ups. If you are quiet in the room, post Completed / Next / Blocker in Teams before the call. Charter already requires this; we will actually call on everyone.
- If you disagree, ask one more question before you override. Week 06: under-represented voices default to “go with the flow”. We do not let that happen. Mahima is Frontend Lead; her UI calls are not re-litigated in the last five minutes of a meeting.
- Pair on anything that would otherwise live in one person’s head (charter: T-shaped, no silos).
- English is the working language. Slow down. Do not talk over people.
- WhatsApp is for “I am late” and “the site is down”. Decisions go in Teams or the repo.

## Conflict

Deal with it early (Week 06). Path:

1. Two people, same day, in Teams. Facts, not character.
2. If it still blocks delivery, Tanmoy mediates within 24 hours.
3. If it still threatens client scope or a person’s safety in the team, escalate to Eagle (Wenhao Liang) the same week.

Workload disputes use the board, not feelings. Rebalance in the next planning session.

## Accountability

- A task is not done until it is on the board in **Done** and the artefact or PR exists in this repo.
- PRs need one peer review and Jeet’s security check before merge to main.
- Missed Tuesday review: that person contacts Eagle that week (`plan/cadence.md`).
- We tell the client and mentor the true status. No hiding slipped Must items behind Should polish.

## Product culture (shows up in the UI)

The platform is for every student who might volunteer, not only the people who look like the team.

- Visible **Demo Website** banner so nobody thinks this is an official production system.
- Contrast and text size that we can defend against WCAG 2.2 AA for the screens we ship (Nishanth/Mahima).
- Forms that do not assume a single name format, gender, or that everyone has an Australian mobile.
- Synthetic data only in seeds and screenshots (Jeet). UAT is opt-in and withdrawable (Jay).

## Board

Charter named Jira. Operating board: **GitHub Projects** (board + Roadmap) plus `plan/tasks.csv`, $0 and in the repo. If Eagle requires Asana or TeamGantt, we import the same CSV. We do not rebuild the WBS.
